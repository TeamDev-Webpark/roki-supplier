# โฟล WEBPARK – Supplier

## เริ่มใช้งาน

1. WEBPARK Issue เพิ่มชิ้นส่วน/ชุดประกอบ ผูก Supplier กำหนดจำนวนผลิต แบบ และรอบทบทวน 1 หรือ 3 เดือน
2. เปิดคลังสูตรคำนวณ สร้างชุดสูตรแยกตามลักษณะต้นทุนได้หลายชุด และบันทึกเป็นเวอร์ชัน
3. เปิด “รายการถึงรอบทบทวน” สำหรับงานรอบเดิม หรือ “สร้างคำขอครั้งแรก” สำหรับชิ้นส่วนที่ยังไม่เคยมีใบเสนอราคาหรือส่งคำขอ
4. ตรวจชื่อ Supplier สูตรและเวอร์ชัน จำนวนผลิต แบบ/Revision วันที่ต้องการเริ่มใช้ราคา และกำหนดตอบกลับ แล้วกด “สร้างและส่งให้ Supplier” ได้โดยตรง

## ใครทำขั้นไหน

| ขั้น | บทบาท | การทำงาน |
|---|---|---|
| จัดทำและส่งคำขอ | WEBPARK Issue | เลือกชิ้นส่วน สูตร และรายละเอียด ส่งตรงให้ Supplier โดยไม่ผ่านการอนุมัติคำขอภายใน |
| กรอกต้นทุน | Supplier Issue | รับแบบฟอร์มที่เว้นช่องราคาไว้ กรอกต้นทุน แนบหลักฐาน และส่งอนุมัติภายใน Supplier |
| ตรวจความถูกต้อง | Supplier Approve | ตรวจต้นทุนแล้วอนุมัติส่งกลับ WEBPARK Check |
| ตรวจราคาซื้อ | WEBPARK Check | ตรวจรายละเอียดต้นทุนและราคาที่ระบบคำนวณตามสูตร ส่งต่อ Approve หรือส่งกลับ Supplier แก้ไข |
| อนุมัติขั้นสุดท้าย | WEBPARK Approve | อนุมัติราคาซื้อพร้อม E-sign ราคาจะใช้งานตามวันที่มีผล |

ไม่มีขั้น WEBPARK Issue รับเรื่องอนุมัติใบเสนอราคาอีกครั้งหลัง Supplier ส่งกลับ

## สูตรและราคา

- หนึ่งคำขอเลือกชุดสูตรและเวอร์ชันต่างกันในแต่ละรายการได้
- การทบทวนรอบใหม่เสนอสูตรจากคำขอรอบก่อนหรือใบที่อนุมัติแล้วให้ก่อน ผู้จัดทำเปลี่ยนได้
- ชิ้นส่วนใหม่เลือกจากชุดสูตรและเวอร์ชันที่รองรับรูปแบบชิ้นส่วนนั้น
- คำขอที่ส่งแล้วบันทึกเวอร์ชันสูตรและแบบฟอร์มต้นทุนไว้ การสร้าง/แก้สูตรภายหลังไม่เปลี่ยนคำขอหรือใบเสนอราคาที่ออกแล้ว
- คัดลอกรายละเอียดเดิม เช่น วัสดุ น้ำหนัก และกระบวนการเป็นแบบตั้งต้นได้ แต่เว้นช่องอัตราราคาและจำนวนเงินให้ Supplier กรอกใหม่
- ราคาซื้อเป็นผลคำนวณจากต้นทุนของ Supplier ตามสูตรที่ระบุในคำขอ ไม่ใช่ราคาที่จัดซื้อกรอกแทน
- เปรียบเทียบกับใบเดิมโดยใช้สูตรของแต่ละเอกสารเอง และเก็บราคาที่เคยอนุมัติไว้

## การจัดการสูตร

WEBPARK Issue และ Approve สร้างชุดสูตรใหม่ เปลี่ยนชื่อ เลือกรูปแบบชิ้นส่วน/ชุดประกอบ แก้คอลัมน์ ชนิดข้อมูล เงื่อนไขบังคับกรอก ค่าเริ่มต้น นิพจน์การคำนวณ เปอร์เซ็นต์ ฐานกำไร และการปัดเศษได้ เพิ่ม ลบ หรือเรียงหมวดต้นทุนได้ การบันทึกการแก้ไขต้องมีเหตุผลและสร้างเวอร์ชันใหม่เสมอ

## สถานะและการติดตาม

เมนูหลักแบ่งเป็นสามกลุ่ม:

| กลุ่ม | หน้า | ใช้เมื่อ |
|---|---|---|
| กำหนดเวลาและสร้างคำขอ | รายการถึงรอบทบทวน | ตารางแรกเป็นรายการถึงรอบที่ยังไม่ส่ง ตารางถัดไปเป็นรอบที่ส่งแล้วและกำลังดำเนินการ รายการจะไม่ซ้ำกันระหว่างสองตาราง |
| กำหนดเวลาและสร้างคำขอ | กำหนดการที่ใช้งาน | ดูทะเบียนกำหนดการทั้งหมด กรองรอบถัดไป ถึงรอบ หรือส่งคำขอแล้ว Issue แก้กำหนดการได้ |
| กำหนดเวลาและสร้างคำขอ | สร้างคำขอครั้งแรก | เฉพาะ Issue เลือกชิ้นส่วนที่ยังไม่เคยเสนอราคาหรือส่งคำขอ |
| คำขอและราคาซื้อ | ติดตามคำขอทั้งหมด | กรองรอ Supplier / รอ Check / รอ Approve / ยังไม่ส่ง / ประวัติ |
| คำขอและราคาซื้อ | งานตรวจต้นทุนของฉัน / งานอนุมัติราคาของฉัน | งานที่รอบทบาทปัจจุบันดำเนินการ |
| ข้อมูลอ้างอิง | ชิ้นส่วนและชุดประกอบ / คลังสูตรคำนวณ / รายงานและประวัติ | ดูข้อมูลต้นทาง สูตร และหลักฐานการดำเนินงาน |

ไม่มีหน้าฉบับร่างแยกอีกต่อไป รายการที่บันทึกไว้ก่อนยังอยู่ในตัวกรอง “ยังไม่ส่ง” ของหน้าติดตามคำขอ และเปิดดำเนินการต่อได้ ข้อมูลเดิมไม่ถูกลบ

กดพื้นที่แถวในตารางกำหนดการหรือรายการถึงรอบเพื่อเปิดหน้าติดตามโฟลของชิ้นส่วนนั้น กดแถวคำขอเพื่อดูรอบที่ส่งจริง กดแถวใบเสนอราคาเพื่อดูรายละเอียดต้นทุนและการอนุมัติ ปุ่มแก้ไข ช่องเลือก และลิงก์เอกสารยังทำงานแยกจากการเปิดแถว ใช้ Tab แล้ว Enter หรือ Space เปิดรายละเอียดได้เช่นกัน

รายการถึงรอบที่ยังไม่มีคำขอค้างมีปุ่ม “ส่งคำขอทบทวนราคา” ท้ายแถว ทั้งในหน้ารายการถึงรอบและทะเบียนกำหนดการ กดเพื่อเปิดรายละเอียดรายการเดียว ตรวจสูตรและวันตอบกลับ แล้วสร้างและส่งได้โดยไม่ต้องเลือกช่องก่อน รายการที่บันทึกไว้แล้วใช้ “ตรวจและส่งคำขอ” เพื่อดำเนินการฉบับเดิมต่อ

ช่องเลือกใช้รวมหลายชิ้นส่วนในคำขอฉบับเดียว ต้องเป็น Supplier บริษัทเดียวกัน เมื่อเลือกชิ้นส่วนแรกจะล็อกบริษัทและปิดช่องเลือกของบริษัทอื่น เลือกทั้งหมดจะรวมเฉพาะบริษัทที่เลือก หากยังไม่เลือกชิ้นส่วนและหน้าปัจจุบันมีหลายบริษัท ให้เลือกชิ้นส่วนแรกหรือกรอง Supplier ก่อน กด “ล้างรายการ / เปลี่ยน Supplier” เพื่อเลือกบริษัทใหม่ หน้ายืนยันแสดงผู้รับและจำนวนชิ้นส่วน แต่ละชิ้นส่วนมีแบบฟอร์มต้นทุนและเวอร์ชันสูตรของตน ระบบตรวจบริษัทซ้ำก่อนบันทึกและส่ง ไม่รวมต่าง Supplier ในคำขอใหม่ฉบับเดียว ประวัติคำขอเก่าที่ส่งไปแล้วไม่เปลี่ยนแปลง

หน้าติดตามโฟล หน้าชิ้นส่วน/ชุดประกอบ หน้าคำขอ และหน้าใบเสนอราคา มีประวัติใบเสนอราคาของชิ้นส่วนและ Supplier เดียวกัน แสดงเลขที่ใบ Revision วันที่เสนอ วันที่มีผล คำขอต้นทาง เวอร์ชันสูตร ราคาคำนวณ และสถานะ เปิดใบเก่าเพื่อดูต้นทุนกับหลักฐานการอนุมัติของใบนั้นได้ ข้อมูลต่าง Supplier และฉบับร่างภายในที่บัญชีปัจจุบันไม่มีสิทธิ์จะไม่แสดง ส่วนแถวรายละเอียดต้นทุนที่ไม่มีเอกสารแยก เปิดหน้าต่างแสดงข้อมูลแถวนั้นได้

ตารางติดตามแสดงหนึ่งแถวต่อชิ้นส่วนและ Supplier ในแต่ละคำขอ พร้อมสถานะเดียว ผู้รับผิดชอบปัจจุบัน และปุ่มหลักตามบทบาท จำนวนบนเมนูและตัวกรองนับจากรายการเดียวกับตาราง ใบเสนอราคาที่ยังเป็นฉบับร่างภายใน Supplier จะไม่เปิดเผยให้ WEBPARK

การเตือน Supplier เกินกำหนดแสดงเฉพาะรอบปัจจุบันที่ยังอยู่กับ Supplier เมื่อส่งกลับมารอ WEBPARK Check หรือ Approve แล้วจะไม่เตือนว่า Supplier ยังส่งช้า รอบล่าสุดอ้างอิงวันเวลาที่ส่งจริง ไม่อ้างลำดับการนำเข้าข้อมูล

ไทม์ไลน์แยก “การจัดทำและส่งคำขอ” ออกจาก “การเสนอและอนุมัติราคาซื้อ” ฝั่งหลังส่งมีสี่ขั้นคือ Supplier Issue → Supplier Approve → WEBPARK Check → WEBPARK Approve ประวัติอนุมัติคำขอก่อนส่งของข้อมูลระบบเก่ายังเปิดดูได้ในส่วนประวัติเดิมที่พับไว้ โดยไม่นำมาเป็นขั้นตอนบังคับของโฟลใหม่

คำขอแยกเป็นฉบับร่าง ส่งแล้ว และยกเลิก ไม่มีคิวอนุมัติคำขอก่อนส่ง ใบเสนอราคามีฉบับร่าง รอ Supplier อนุมัติ รอ WEBPARK Check รอ WEBPARK Approve อนุมัติแล้ว ส่งกลับแก้ไข และปฏิเสธ

เปิดเอกสารต้นทาง แบบฟอร์มที่ส่ง ใบเดิม ใบใหม่ และไทม์ไลน์ได้จากรายละเอียดคำขอ/ชิ้นส่วน การส่งกลับแก้ไขจะให้ Supplier Issue แก้ไขและผ่าน Supplier Approve ใหม่

## ข้อมูลเดิม

คำขอเดิมที่ยังไม่ส่งและยังไม่ปิดจะเปลี่ยนเป็นฉบับร่างให้ Issue ตรวจแบบฟอร์มแล้วส่งตรง ประวัติการอนุมัติเก่ายังคงเก็บไว้ ใบเสนอราคาที่เคยรอ WEBPARK Issue จะย้ายให้ Check โดยไม่มีการสร้างลายเซ็นหรืออนุมัติแทน ใบที่อนุมัติแล้วและราคาย้อนหลังคงเดิม

ระบบนี้เป็นเดโมในเบราว์เซอร์ การส่งคำขอ การแจ้งเตือน และ E-sign เป็นการจำลอง ไม่มีอีเมลหรือฐานข้อมูลเซิร์ฟเวอร์จริง

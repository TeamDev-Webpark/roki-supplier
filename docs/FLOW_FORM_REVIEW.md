# ตรวจโฟลและรายละเอียดใบเสนอราคาเทียบเอกสารลูกค้า

ตรวจเมื่อ 23 พ.ย. 2026 · เทียบระบบใน `design-demos` กับไฟล์ใน `docs`:
`sample -QT.xls` (5 ชีต), `QT-COMPONENT.pdf` (HOLDER), `PART STEEL.pdf` (GUARD ELEMENT / PLATE / MESH 3 หน้า), `QT-ASSY.pdf` (CASE ASSY Rev.10 / Rev.11) และสรุปประชุม `โรกิ (ประเทศไทย) จำกัด (2).pdf`

วิธีตรวจ: เดินโฟลจริงในเบราว์เซอร์ด้วยบัญชี ROKI Issue → Supplier Issue → ROKI Check แล้วเก็บรายการช่องกรอกทุกหน้า (ช่องบังคับ / แก้ได้ / อ่านอย่างเดียว) เทียบกับหัวเอกสาร ตาราง และช่องลงนามของฟอร์มลูกค้าทีละช่อง

## สรุป

- **การคำนวณ**: ชุดสูตร Injection / Rubber / Steel / QT-ASSY คำนวณตรงตัวอย่างลูกค้าแล้ว (มีเทสต์ยืนยัน)
- **แต่ข้อมูลที่ต้องกำหนดตอนสร้างคำขอ (ROKI Issue) ยังไม่ครบ**: ระบบเสนอสูตรมาตรฐานเดิม (v1) แทนสูตรตามชนิดงาน, ไม่มีหน่วยช่วงเวลาของปริมาณ, ไม่มีวันสิ้นสุดราคา, ไม่ระบุชิ้นส่วนที่ ROKI จ่ายให้ (Supply) และไม่มีเงื่อนไขการค้า
- **Supplier แก้ค่าที่ ROKI กำหนดได้**: วันที่เริ่มใช้ ปริมาณ Revision และ % กำไร/ฐานคิด/ค่าอะไหล่
- **หน่วยและรูปแบบบรรทัดบางแบบในใบลูกค้ายังกรอกตรงๆ ไม่ได้**: น้ำหนักเป็นกรัม, เวลาเป็นนาที, กระบวนการที่ให้แค่ "ราคา" ไม่มีเวลา×อัตรา
- **ใบพิมพ์**: หัวเป็น WEBPARK ไม่ใช่หัว ROKI, ไม่มีรหัสฟอร์ม APQ1.0.2, ไม่มีวันสิ้นสุดและเลขที่ใบของ Supplier

## โฟลปัจจุบัน

1. ROKI ตั้งชิ้นส่วน (part master) ผูก Supplier และประเภทฟอร์ม (Single Part / Assembly)
2. ROKI Issue เลือกรายการที่ถึงรอบ → หน้า "สร้างคำขอให้ Supplier กรอกต้นทุน" → ส่งแบบฟอร์มเปล่า
3. Supplier Issue กรอกต้นทุน → Supplier Approve อนุมัติส่ง
4. ROKI Check → ROKI Approve (e-sign) → ราคา Active

โฟลตรงกับที่ประชุมสรุป (Supplier กรอกเอง, ROKI 3 ระดับ, e-sign ฝั่ง ROKI, Revert/Reject, แยกรูปภาพกับ Drawing, เก็บประวัติ)
ข้อที่ควรยืนยันกับลูกค้า: ROKI **Issue** ลงนามตอนสร้างคำขอ ไม่ได้ตรวจใบที่ Supplier ส่งกลับ ส่วนในใบกระดาษ ช่อง "Issued by" ของ ROKI ลงนามบนใบที่ Supplier กรอกแล้ว

## ช่องในเอกสารลูกค้า เทียบกับระบบ

| ช่องในเอกสารลูกค้า | อยู่ในเอกสาร | ระบบตอนนี้ | สถานะ |
|---|---|---|---|
| Supplier Code / Name | ทุกฟอร์ม | จาก master | ครบ |
| Part No. / Part Name | ทุกฟอร์ม | จาก master | ครบ |
| Rev. No. (เช่น M206-F-26, M-19-F0461) | ทุกฟอร์ม | "Drawing revision" ในคำขอ (บังคับ) | ครบ แต่ Supplier แก้ได้ |
| RTP Code | ทุกฟอร์ม | master ไม่บังคับ, หน้าคำขอไม่แสดง/ไม่ตรวจ | **ขาด** |
| Qty/Y (Unit Part), Qty/M (QT-ASSY), Qty/2Y (ชิ้นส่วนย่อยใน Excel) | ทุกฟอร์ม | "Production volume" ไม่มีหน่วยช่วงเวลา | **ขาดหน่วย** |
| Date ของใบ | ทุกฟอร์ม | วันที่ระบบบันทึก | ครบ |
| Beginning (วันเริ่มใช้ราคา) | ทุกฟอร์ม | "Requested effective date" | ครบ แต่ Supplier แก้ได้ |
| **Ending** (วันสิ้นสุดราคา) | QT-ASSY (01–31 May 2026) | ไม่มีทั้งคำขอ ฟอร์ม Supplier และใบพิมพ์ | **ขาด** |
| ช่วงราคาใน Remark ("period Apr–Jun 2026") | QT-COMPONENT | เป็นข้อความอิสระ | ควรเป็นวันเริ่ม–สิ้นสุด |
| เลขที่ใบของ Supplier "No. QTFGY2402-002" | QT-ASSY | ไม่มีช่อง | **ขาด** |
| "Cost Rev.10 / Rev.11", "Cost Original / Revise 1st" | ทุกฟอร์ม | Revision ของระบบ + ใบพิมพ์ 2 คอลัมน์ | ครบ |
| "(Buy U Part from Roki)" / คอลัมน์ Supply | QT-ASSY, Component (B) | Supplier เลือก Supply เอง, BOM สร้างแถวแต่ไม่ระบุว่า ROKI จ่ายชิ้นไหน | **ขาดในคำขอ** |
| Notes เงื่อนไขการค้า (ไม่รวม VAT, เครดิต 60 วัน, คืนทุนแม่พิมพ์, MN cost เริ่มปีที่ 2) | QT-ASSY, QT-COMPONENT | ใบพิมพ์มี "ไม่รวม VAT" ข้อเดียว ไม่มีช่องอื่น | **ขาด** |
| Remark เหตุผลเปลี่ยนราคา | ทุกฟอร์ม | บังคับกรอก | ครบ |
| รูปภาพชิ้นงาน ~10 รูป แยกจาก Drawing PDF | ประชุม 10 พ.ย. | Supplier แนบรูป ≤10 + Drawing; ROKI แนบ Drawing ≤5 | ครบ |
| ช่องลงนาม Supplier | PDF: Approved / Issued · **Excel: Approved / Checked / Issued** | 2 บทบาท (Issue, Approve) | ต้องยืนยัน |
| ช่องลงนาม ROKI: Approved / Checked / Issued | ทุกฟอร์ม | ครบ, e-sign จำลอง | ครบ |
| หัวกระดาษ ROKI (THAILAND) + ที่อยู่, รหัสฟอร์ม "APQ1.0.2 Rev.No:6" | ทุกฟอร์ม | ใบพิมพ์ใช้หัว WEBPARK ไม่มีรหัสฟอร์ม | ต้องยืนยัน |

## ต้องถามลูกค้า (เอกสารขัดกันหรือไม่ระบุ)

1. ชิ้นส่วนย่อยต้องมีกำไร/ค่าอะไหล่ไหม (PART STEEL ไม่มี, Excel มี 15%+15%)
2. ช่องลงนาม Supplier เป็น 2 ระดับ (PDF) หรือ 3 ระดับ (Excel: Approved / Checked / Issued)
3. ROKI Issue ต้องตรวจใบที่ Supplier ส่งกลับด้วยไหม หรือแค่สร้างคำขอ
4. ใบพิมพ์ต้องเป็นหัว ROKI และรหัสฟอร์ม APQ1.0.2 หรือไม่
5. หน่วยมาตรฐาน: กรัมหรือกิโลกรัม, วินาทีหรือนาที (เอกสารใช้ปนกัน)
6. ราคามีวันสิ้นสุดทุกใบหรือเฉพาะ Assembly; Qty ต่อปีหรือต่อเดือนตามประเภท
7. เงื่อนไขการค้า (VAT, เครดิต, คืนทุน, MN cost) เป็นค่ากลางของ ROKI หรือ Supplier เสนอเอง
8. ข้อที่ค้างจากรอบก่อน: การจัดสรรต้นทุน Common tool, ฐาน Set-up loss, interest ฝั่ง revised ของ Excel (ดู `design-demos/QUOTATION-MAPPING.md`)

| # | แก้อย่างไร |
|---|---|
| 1 | ข้อมูลชิ้นส่วนมีช่อง "ชุดสูตรของชิ้นส่วนนี้" (เลือกได้เฉพาะชุดที่ตรงประเภทฟอร์ม, นำเข้า CSV คอลัมน์ `formula_set` ได้) คำขอใช้ชุดนี้เป็นค่าเริ่มต้น; ถ้าไม่ได้กำหนดและไม่มีประวัติ ต้องเลือกเอง ไม่มีค่าเดาให้ ชิ้นส่วนตัวอย่างผูกชุด Injection / Rubber / Steel / QT-ASSY แล้ว |

| 4 | กำหนดตอบกลับค่าเริ่มต้น = วันนี้ + 14 วัน และต้องก่อนวันเริ่มใช้ราคาทุกชิ้นส่วน |

| 6 | ชิ้นส่วนที่มี BOM: Issue ติ๊กชิ้นที่ ROKI จ่ายให้และใส่ราคา → ฟอร์ม Supplier เป็น Supply ราคาคงที่ แก้ไม่ได้ |
| 7 | คำขอมีเงื่อนไขการค้า: VAT, เงื่อนไขชำระเงิน (บังคับ), เงื่อนไขอื่น → แสดงให้ Supplier และพิมพ์ท้ายใบ |
| 8 | คำขอมี "วัสดุ / เกรดที่ต้องการ" ต่อชิ้นส่วน แสดงให้ Supplier |

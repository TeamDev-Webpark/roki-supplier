# วิเคราะห์: หน้าคลังสูตรคำนวณที่สร้าง/แก้สูตรให้เหมือนฟอร์มเอกสารลูกค้า

วิเคราะห์เมื่อ 24 พ.ย. 2026 จากหน้า "คลังสูตรคำนวณ" (`#formulas`) ที่มีอยู่ เทียบกับ `sample -QT.xls` (5 ชีต), `QT-ASSY.pdf`, `QT-COMPONENT.pdf`, `PART STEEL.pdf`

## สรุป

**ควรทำต่อ แต่ไม่ต้องสร้างหน้าใหม่ — ควรยกระดับหน้าคลังสูตรเดิมจาก "ตัวคำนวณ" เป็น "แม่แบบฟอร์ม + สูตร + ตัวอย่างยืนยัน"**
ตอนนี้หน้าเดิมจัดการ *การคำนวณ* ได้ดี แต่ *หน้าตาและข้อกำหนดของฟอร์ม* ที่เอกสารลูกค้ามีอยู่ยังฝังอยู่ในโค้ด ทำให้ ROKI สร้างฟอร์มรูปแบบใหม่ที่ "เหมือนเอกสารตัวอย่าง" เองไม่ได้

## หน้าคลังสูตรปัจจุบันทำอะไรได้แล้ว

- สร้าง / เปลี่ยนชื่อชุดสูตร แยกตามประเภทฟอร์ม (Single Part, Assembly) และเวอร์ชันพร้อมเหตุผล ประวัติ ใช้เวอร์ชันเก่าเป็นฉบับร่าง
- เพิ่ม / ลบ / เลื่อนหมวดต้นทุน, เพิ่ม / ลบคอลัมน์ (ชนิด ข้อความ / ตัวเลข / ตัวเลือก, บังคับ, ค่าเริ่มต้น), สูตรต่อแถว, % ปรับ, กำไร, ค่าอะไหล่, ฐานคิด, สูตรยอดรวม, การปัดเศษ, ล็อกค่าที่ Supplier แก้ไม่ได้
- ตรวจสูตรก่อนบันทึก และ Live check ทดลองกับใบเสนอราคาจริง
- ใบที่ออกแล้วคงเวอร์ชันเดิม

## ข้อเสนอ แบ่งเป็นระยะ

### ระยะ 1: ตัวอย่างยืนยัน (Worked examples) — ทำก่อน คุ้มที่สุด
- เก็บ "ตัวอย่างอ้างอิง" ในแต่ละชุดสูตร: ข้อมูลทุกแถว + ผลลัพธ์ที่ลูกค้ายืนยัน (A–E, กำไร, spare, ยอดรวม)
- โหลดตัวอย่างสำเร็จรูปจากเอกสารลูกค้า (Injection / Rubber / Steel 10 บล็อก, QT-ASSY Rev.10/11, ใบกระดาษ GUARD ELEMENT / HOLDER)
- ทุกครั้งที่บันทึกเวอร์ชัน ระบบรันตัวอย่างทั้งหมด แสดงตาราง "ได้ / ต้องได้ / ผ่าน-ไม่ผ่าน" และเตือนถ้าไม่ผ่าน (ให้บันทึกต่อได้ถ้าระบุเหตุผล เพราะลูกค้าอาจตั้งใจเปลี่ยนสูตร)
- ผู้ใช้เพิ่มตัวอย่างของตัวเองได้จากใบเสนอราคาที่อนุมัติแล้ว ("บันทึกเป็นตัวอย่าง")

### ระยะ 2: หน่วย, ชนิดแถว, สูตรอ่านง่าย
- หน่วยและตัวคูณแปลงต่อคอลัมน์ (กรอกเป็นกรัม แล้วระบบแปลงเป็นกก. ในสูตร), ช่อง N/A พร้อมเหตุผล
- ชนิดแถว: "คำนวณ", "ราคาตรง", "ลิงก์ชิ้นส่วนย่อย", "ROKI จ่ายให้", "เปอร์เซ็นต์ของแถวอื่น"
- แสดงสูตรเป็นภาษาคน และปุ่มเลือกชื่อคอลัมน์ใส่สูตร, แสดงการคำนวณทีละขั้นของแถวตัวอย่าง

### ระยะ 3: แม่แบบฟอร์ม (หน้าตาตามเอกสาร)
- กำหนดช่องหัวฟอร์ม (เปิด/ปิด, ชื่อ, บังคับหรือไม่, ใครกรอก: ROKI / Supplier), หน่วยปริมาณเริ่มต้น, ต้องมี Ending หรือไม่
- ชื่อหัวตารางต่อหมวดตามฟอร์ม, ลำดับ, ความกว้างคอลัมน์ในใบพิมพ์
- ท้ายฟอร์ม: รหัสฟอร์ม, หัวบริษัท, Notes มาตรฐาน, ช่องลงนาม (2 หรือ 3 ระดับ)
- ตัวอย่างใบพิมพ์สดในหน้าเดียวกัน เห็นผลทันทีที่แก้

### ระยะ 4: แกลเลอรีแม่แบบและนำเข้า
- "สร้างจากแม่แบบลูกค้า": Injection, Rubber, Steel, QT-ASSY, ฟอร์มกระดาษ — ปรับต่อได้
- (ภายหลัง) นำเข้าไฟล์ Excel ตัวอย่างใหม่: อ่านหัวตารางและสูตรเซลล์ แล้วเสนอคอลัมน์ + สูตร ให้ผู้ใช้ตรวจ ไม่ใส่อัตโนมัติ

### ระยะ 5: การควบคุม
- วันที่มีผลของเวอร์ชัน, ให้ Check / Approve ตรวจก่อนเริ่มใช้, เปรียบเทียบเวอร์ชัน (diff), ปิดใช้งานชุดสูตร
- รายงาน "ใช้ที่ไหน": ชิ้นส่วน คำขอ ใบเสนอราคาที่ผูกกับแต่ละเวอร์ชัน

## หน้าจอที่แนะนำ (ปรับหน้าเดิม ไม่สร้างหน้าใหม่)

แท็บในหน้าคลังสูตร: **ภาพรวมชุดสูตร** (ตาราง ชุด · ประเภท · เวอร์ชัน · ใช้กับกี่ชิ้นส่วน · ผ่านตัวอย่างกี่ข้อ) → **แม่แบบฟอร์ม** → **การคำนวณ** (หน้าปัจจุบัน) → **ตัวอย่างยืนยัน** → **ประวัติและการใช้งาน**

## ข้อควรระวัง

- เอกสารลูกค้าขัดกันเองหลายจุด (ดู `docs/FLOW_FORM_REVIEW.md`) แม่แบบจึงต้องให้ ROKI เลือกได้ ไม่ควรฝังข้อสรุปเดียว
- ระยะ 3–4 ต้องเปลี่ยนโครงใบพิมพ์และฟอร์ม Supplier ให้อ่านแม่แบบแทนโค้ด ใช้เวลามากสุด ทำหลังระยะ 1–2
- ควรให้ลูกค้ายืนยันก่อนทำระยะ 3: หัวฟอร์ม/รหัสฟอร์ม, ช่องลงนาม, หน่วยมาตรฐาน

## ข้อมูลตัวอย่างที่เพิ่มในครั้งนี้

หน้า "สร้างคำขอครั้งแรก" มีชิ้นส่วนรอเสนอราคาครั้งแรกครบทุกชุดสูตร (8 รายการ): Injection, Rubber, Steel (มีชิ้นส่วนย่อย PLATE/MESH), QT-ASSY (Assembly รอบ 1 เดือน), สูตรมาตรฐานชิ้นส่วน, สูตรมาตรฐานชุดประกอบ (มี BOM), สูตรชุดประกอบ และรายการเดิม BRACKET ทุกรายการเลือกสูตรเริ่มต้นตามชุดที่ผูกไว้

## สถานะการทำงาน (24 พ.ย. 2026)

ทำครบทั้ง 5 ระยะในหน้า "คลังสูตรคำนวณ" เดิม (`formulas.js` + `formula-library.js` + `formula-examples.js`):

- ระยะ 1: ตัวอย่างยืนยัน — ชุด Injection / Rubber / Steel / QT-ASSY / ฟอร์มกระดาษ มีตัวอย่างจากเอกสารลูกค้า รันซ้ำทุกครั้งที่แก้ร่าง ถ้าไม่ตรงต้องติ๊ก "บันทึกแม้ตัวอย่างต่าง" และใส่เหตุผล; เก็บใบเสนอราคาเป็นตัวอย่างเพิ่มได้
- ระยะ 2: คอลัมน์ตัวเลือก (หน่วย/ชนิด), ตัวแก้ตัวเลือก, สูตรอ่านง่าย
- ระยะ 3: แม่แบบฟอร์ม — ช่องหัวฟอร์ม, ชื่อหัวตาราง/คอลัมน์ในใบพิมพ์, Notes, รหัสฟอร์ม, ช่องลงนาม, บรรทัดว่าง, ตัวอย่างใบพิมพ์สด (ตรวจความถูกต้องใน `validateFormatConfig`)
- ระยะ 4: "เริ่มจาก" ชุดสูตรใดก็ได้ (คัดลอกแม่แบบ+ตัวอย่างไปด้วย)
- ระยะ 5: วันที่มีผล (เวอร์ชันล่วงหน้าเป็น Scheduled แล้วเลื่อนเป็นปัจจุบันเมื่อถึงวัน), รายงานการใช้งาน, ปิดใช้ชุดสูตร (ซ่อนจากตัวเลือก), เทียบเวอร์ชัน

ยังไม่ทำ: workflow ให้ Check/Approve ตรวจเวอร์ชันสูตรก่อนมีผล, นำเข้า Excel ตัวอย่างใหม่อัตโนมัติ
